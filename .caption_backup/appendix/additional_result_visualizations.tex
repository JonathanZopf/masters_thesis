\section{Distributions of Question-Level Faithfulness and CE}
\label{app:distributions}

Figures~\ref{fig:app-dist-f-bbq-gptoss} to~\ref{fig:app-dist-ce-credit-mistral} show the distributions behind the dataset-level values in Table~\ref{tab:results-dataset-overview}. Each panel combines a density estimate (cloud), one point per evaluated question (rain), and a horizontal boxplot (umbrella) whose center line marks the median. The faithfulness panels additionally report the dataset-level estimate $\mathcal{F}(\mathbf{X})$. For CE, the plotted value of each question is the arithmetic mean of its concept-level CE values. The atomic and interaction-aware values originate from the same joint FELICS run as described in Section~\ref{sec:controlled_atomic_baseline}. Thus, extracted concepts and responses are fixed within each comparison. The CE axes are shared between the two models of a dataset but differ across datasets because their CE magnitudes differ substantially.

The two variables are defined in Section~\ref{sec:methodology-preservation}, and their arguments are omitted here to save space. The dashed line denotes unchanged CE magnitude, and darker regions indicate overlapping observations. These identity plots visualize changes in CE magnitude rather than constituting additional rank-preservation tests. Each caption reports the number of concept-level values and the aggregate Spearman correlation $\rho$ from Box~\ref{hyp:hyp3-results}.
